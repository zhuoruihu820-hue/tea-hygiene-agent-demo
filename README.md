# 净巡：茶饮卫生检查 Agent Demo

## 背景

本 Demo 演示店长选择门店并上传巡检照片、Agent 根据版本化规则输出检查结果、店长提交整改照片、督导复核并关闭任务的完整闭环。系统采用“证据不足即无法判断”的保守策略，不以大模型常识替代已启用规则。

在线体验：[净巡 · 茶饮卫生巡检 Demo](https://tea-hygiene-agent-demo.austin0922.chatgpt.site)

## 使用环境

- Node.js 22.13 或更高版本
- Next.js 16、React 19、TypeScript
- Cloudflare Workers 兼容的 Sites 运行环境
- 支持视觉输入的通义千问 OpenAI 兼容接口

## 依赖与启动

```bash
npm install
cp .env.example .env.local
# 在 .env.local 中填写 DASHSCOPE_API_KEY
npm run dev
```

生产环境中将 `DASHSCOPE_API_KEY` 配置为服务端密钥，禁止写入浏览器代码或提交到仓库。

## 输入、规则与输出

- 输入：门店、检查项、手机拍摄或相册上传的图片；首期卫生规则已内置。
- 规则：`app/api/inspect/route.ts` 中的 `RULES` 是唯一判定依据。服务端会强制写回对应的规则编号和原文；图片模糊、过暗、遮挡或区域未入镜时，必须输出“无法判断”。
- 输出：检查项、是否违规、图片证据、规则编号与原文、风险等级、整改建议、置信度和无法判断原因。

## 项目结构

```text
app/
├── page.tsx                 # 移动端店长/督导闭环界面
├── globals.css              # 纸张手帐风视觉样式
└── api/inspect/route.ts     # 真实视觉模型调用与规则约束
public/samples/              # 用户提供的自测巡检图片
.env.example                 # 服务端模型配置示例
```

## 自测样例

1. 点击“载入自测样例”，载入“垃圾桶桶盖开启且垃圾满溢”的图片和预置结果。
2. 在店长视图点击“提交整改后照片（演示）”。
3. 切换督导视图，点击“督导复核通过并关闭”。
4. 配置密钥后，上传任意巡检图并点击“开始检查”，即可触发服务端视觉模型分析。

## 延迟与质量控制

服务端调用 `qwen3.8-max` 时关闭内部思考模式，仅要求其输出固定规则下的结构化结论；图片、规则原文、风险映射和输出字段均未删减。每次规则或模型参数调整后，应使用同一组人工标注图片比较违规召回率、误报率和无法判断准确率，再决定是否保留该优化。

## 测试建议

每个检查项分别测试合规、违规和无法判断样本；以人工标注为金标准，统计违规召回率、误报率、无法判断准确率和不同督导的一致性。调整提示词或规则版本时，应保持测试集不变并进行消融比较。
